# Cheat sheets

There is no separate on-desktop cheat-sheet file. `render-tasks.py` (the script that turns each
condition's task markdown into the interactive task page participants saw) treats a
`## Command cheat sheet` section inside the task markdown as the cheat sheet, and mirrors it into
an overlay reachable from a button in the task page's sticky bar.

Only the **Serenade** condition's task file has such a section — Cursor and Mantra rely on the
tool's own affordances (a chat box; a VS Code panel) rather than a spoken-command reference, so
there is no `cheat_sheet_cursor.*` or `cheat_sheet_mantra.*`.

`cheat_sheet_serenade.md` here is that section, copied verbatim from `study_materials/tasks/tasks_serenade.md`.
