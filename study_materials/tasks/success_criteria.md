# Success criteria

The 11 tasks shown to participants (identical across the three tool conditions — only the
surrounding instructions differ, see `tasks_cursor.md` / `tasks_mantra.md` / `tasks_serenade.md`),
with the criterion used to count each as complete.

| # | Task | Success criterion |
|---|------|--------------------|
| 1 | Open a file and navigate to a line | Correct file is open and the viewport is near line 200 |
| 2 | Select a block and move it | Block moved correctly without syntax errors |
| 3 | Edit a block (duplicate, add line, delete line) | All three edits completed correctly |
| 4 | Symbol navigation | Both symbols reached and navigation back succeeds |
| 5 | Run a program | Program runs and expected output appears |
| 6 | Debug | Debugger is active and variable inspection succeeds |
| 7 | Search and replace | Exactly 3 correct replacements |
| 8 | Run tests and navigate to a failure | Tests run and the failing test's location is opened |
| 9 | Refactor (extract duplicated normalization logic) | Refactor is correct and tests pass |
| 10 | Version control (stage, commit, push) | Push completes |
| 11 | Format | File is formatted correctly |
