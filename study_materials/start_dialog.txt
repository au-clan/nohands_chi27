[cursor]
Tool name shown: Cursor
Use Cursor to complete the tasks by speaking to the AI. Cursor is not running yet — it opens when
you click OK on the next box ("Ready to start?"). Once Cursor has opened: click the microphone
icon in the Cursor chat panel, speak your intent, and let Cursor apply it. Avoid typing code
manually.

[serenade]
Tool name shown: Serenade
Use Serenade to complete the tasks by speaking commands aloud. Serenade is not running yet — it
starts when you click OK on the next box ("Ready to start?"). Once it has started: its icon
appears in the system tray at the bottom-right of this desktop (not your own computer's taskbar);
a green dot means it's listening. Serenade sends commands to whichever window you last clicked —
after clicking the task list, say "focus code" to point it back at VS Code. Avoid using the
keyboard as much as possible.
(Serenade condition also appends: "Scroll down to the Command cheat sheet section, or click the
⌨ Cheat sheet button in the dark bar at the top of the page — you can reopen it at any point
during the session.")

[mantra]
Tool name shown: Mantra
Use the Mantra VS Code extension to complete the tasks by voice. VS Code is not running yet — it
opens when you click OK on the next box ("Ready to start?"). Once VS Code has opened: the Mantra
panel is on the right-hand side of the window (the file explorer stays on the left). Click
Hands-Free Mode (or hold Push to Talk) and speak your command. Avoid using the keyboard as much
as possible.
